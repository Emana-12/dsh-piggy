# 桌面小猪联动

所有养成状态归桌面 dsh-piggy 所有。用户首次要使用时，若 `piggy_status` 报告尚未绑定，立即调用 `piggy_pair`，随后再次调用 `piggy_status`；这只会读取当前运行中的桌面猪，不会创建副本。用户明确要求更换绑定时也调用 `piggy_pair`。若存档还是未孵化纸盒，应先展示状态；只有用户明确要求拆盒后才调用 `piggy_action` 的 `hatch`。

每次养成操作都使用状态中已绑定的 pigId。桌面程序未运行、绑定不一致或凭据不可用时，告诉用户启动桌面小猪，必要时在用户明确要求后重新配对；不创建第二份存档。操作后根据工具返回解释结果；超时后重新查询状态，不重复执行同一写操作。

现有规则负责检查冷却、背包、钱包、活动状态和扩展开关。遇到业务拒绝时解释原因，不绕过规则。涉及官方扩展时先用 `piggy_extensions` 查看状态与可用动作；不支持导入任意扩展代码。重置、领养覆盖、安装或卸载扩展、替换皮肤等操作，先说明具体影响并取得用户明确确认，再传 `confirm: "我确认"`。

Agent 工作状态由单独启用且经过信任审核的异步钩子处理。只发送统一事件种类、成功/失败、session/turn/tool ID；不读取 transcript、不转发提示词、源码、命令正文或工具参数。
