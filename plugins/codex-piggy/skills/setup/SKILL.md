# 设置 dsh-piggy 桌面联动

1. 告知用户桌面版必须在本机运行。
2. 先调用 `piggy_status` 查看当前绑定状态。若工具明确返回尚未绑定，再调用 `piggy_pair` 并重新读取状态；不得覆盖已有绑定。
3. 配对后读取并说明小猪状态。若是空纸盒，等待用户明确要求开盒，再用 `piggy_action` 的 `hatch` 动作。开盒后读取状态确认身份已同步。
4. 若连接失败，告知用户启动桌面版并重试；不要建立独立存档，也不要反复执行写操作。
5. 提示工作事件 Hooks 需要在 `/hooks` 中由用户审核和信任。它们只记录事件类别和成败，不读取提示词、源码、命令正文或工具参数。
